# Book Recommendation Chatbot using IBM Watson Assistant

## Overview

This project is a conversational chatbot designed using IBM Watson Assistant concepts. The chatbot recommends books based on:

- Genre
- Author
- Mood

## Features

- Book recommendations by genre
- Book suggestions by author
- Mood-based recommendations
- Greeting and goodbye responses
- Fallback response for unknown queries

## Intents

- Greeting
- Goodbye
- Recommend Book
- Genre Search
- Author Search
- Mood Search
- Thanks

## Entities

- Genre
- Author
- Mood
